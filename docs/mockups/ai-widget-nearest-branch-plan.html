AI widget · plan for review · 2 October 2026

Suggest the nearest branch to domestic visitors

When someone in the institution's own country asks about applying, studying or visiting, the widget shows the branch nearest to them. Nothing below is built; it waits for your review.

● Waiting for your review
00

What you decided

Visitor location
Automatic, from the location headers Cloudflare adds to each request. The header names are read from .env, so no provider is baked into the code.
"Closest"
Matched on the branch's own city, state and country columns, with the address shown. No geocoding, no coordinates, no Google calls.
01

Configuration

Two env variables, each naming a header. cf-ipcountry is on by default in Cloudflare; cf-region needs "Add visitor location headers" turned on (Rules › Managed Transforms). Leave the region unset and matching is by country only.

Env variableCloudflare headerUsed for
GEO_COUNTRY_HEADERcf-ipcountryDomestic or not (ISO code, e.g. AU), and the country fallback
GEO_REGION_HEADERcf-regionState name, e.g. "Victoria": matched against each branch's state, and shown to staff

The headers must reach Fastify through nginx unchanged. The existing TRUST_PROXY rule is unaffected.

03

In the chat (guest route)

  • Every visitor message: read the two headers named in env. Store country and region on the visitor row (a separate, best-effort write, like the profile).
  • Domestic: the location country matches the country of the institution's branches. If the visitor told the assistant a nationality that differs, they're international.
  • When: the visitor is domestic, at least one branch is located, no branch was suggested in this chat yet, and the message is about applying, enrolling, studying, campuses, visiting or "near me". A small word check decides that; no extra AI call.
  • Which, first match wins: a branch whose state matches the visitor's region ("Campus in your state"); else the primary branch in their country, or the first one ("Our main campus"). Matching ignores case, spaces and punctuation. The visitor's ISO country code (AU) is turned into the branch's country name through globalyapp.countries.
  • The branch goes into the AI's context for that turn (name, address, why it matched), so the reply can mention it. A nearest-branch card event follows the reply: name, address, phone, the match ("Campus in your state" or "Our main campus"), a plain Google Maps search link for the address (no API), and the full list, best match first.
  • No headers, no branch in the visitor's country, or an overseas visitor: nothing changes.

05

Risks and limits

  • Privacy: this locates visitors without asking. It's city-level and the coordinates aren't stored, but the privacy notice on the institution's site should mention it.
  • Spoofing: outside Cloudflare, anyone can send these headers. The worst case is a wrong campus suggestion, so it's acceptable; keep nginx from passing client-set cf-* headers when not behind Cloudflare.
  • Accuracy: it's state-level. Two branches in the same state aren't told apart (the first, or the primary, wins), and one in a neighbouring state is never preferred over the main campus.
  • Spelling: Cloudflare sends the full state name ("Victoria"), so a branch whose state is stored as "VIC" won't match. Store full state names on branches; the Branches hint flags blanks.
  • Cost: none. No external calls.
  • Branch ≠ course: branches aren't linked to courses, so the card can't say which campus teaches what.
  • The Google Maps key isn't used by this feature. It appeared in our chat earlier; consider rotating it.
06

How we'll check it

  • Pure tests: header parsing from env names, the domestic rule, state → country matching (case and punctuation), the "about applying" word check, once per chat.
  • Backend and frontend typecheck and lint; migrations imported with a fake database.
  • You run the migrations, set the env header names, and turn on Cloudflare's location headers. Then a chat from inside the country gets the card, and one via a VPN abroad doesn't.
  • Locally, without Cloudflare, send the headers yourself (curl -H "cf-ipcountry: AU" …) to test.
