# Partner logos

Logos for the education counselors / agencies shown in the marketing-page mockups. Drop a file
in with the exact name below and it appears automatically — the card uses `AvatarImage`, which
falls back to a monogram for as long as the file is missing, so a gap never breaks a page.

| File | Partner | Used by |
| --- | --- | --- |
| `apex-education-partners.png` | Apex Education Partners, Dubai UAE | [partnership-connect-mockup.tsx](../../src/app/(web)/components/mockups/partnership-connect-mockup.tsx) |

Apex is a placeholder name. If you swap in a real partner counselor, rename the persona in the
mockup to match and name the file after it.

Square, transparent PNG, 256×256 or larger — the tile renders it `object-contain`, so wide
wordmarks shrink to unreadable. Institution logos live in [../institutions](../institutions).
